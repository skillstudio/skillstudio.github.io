# img skills

Privacy-first professional image tools that run locally in your browser.

The first tool is an Image Compressor for JPG, PNG, and WEBP files. Images are processed with browser APIs and are not uploaded to a server.

## Features

- Local browser processing
- Batch image compression
- Adjustable compression quality from 10% to 100%
- Output as original format, JPG, or WEBP
- Responsive layout for desktop, Android, iOS, phones, and tablets
- Static deployment to GitHub Pages
